# oil_now 디자인 방향 (Design Direction)

작성일: 2026-06-13
용도: 전체 UI 디자인 개편의 기준 문서. 이 문서를 `/impeccable init` 입력으로 사용하여 DESIGN.md / PRODUCT.md를 생성한다.

---

## 1. 제품 맥락 (Product Context)

- **무엇:** 실시간 유가·주변 주유소·유가 뉴스를 보여주는 한국 유가 대시보드 (모바일 우선 웹앱).
- **대상 사용자:** 모바일에서 **빠르게 싼 주유소를 찾으려는 일반 운전자**.
- **핵심 사용 맥락:** 짧게 흘긋 보는 글랜스(glance) 사용. 정보를 빠르게 읽고 결정.
- **포지셔닝:** 친근한 소비자 앱 (토스·배민·당근 결). 공공기관/금융 톤이 아니라 따뜻하고 밝은 톤.
- **보이스:** 다정하고 명료한 한국어. 과장·전문용어 지양. 숫자가 주인공.

## 2. 브랜드 성격 (Personality)

- **친근한 소비자 앱.** 둥근 카드 + 부드러운 그림자 + 다정한 톤.
- 밝고 따뜻하되, **정돈되어 신뢰감**이 있어야 한다 (유가=돈 관련 정보).
- 라이트 모드 단일. **다크모드는 MVP 범위 밖**(보류).

## 3. 안티레퍼런스 (Anti-References) — 반드시 피할 것

- **클로드(Claude) 홈페이지 룩 금지:** 크림/베이지 배경(#F0EEE6 계열), 점토색·테라코타 오렌지(#D97757 계열), 세리프 디스플레이 폰트. 이 3박자 조합이 핵심 회피 대상.
- **전형적 "AI 디자인 냄새" 금지:** 보라색→파란색 그라데이션, 의미 없는 글래스모피즘, 중첩 카드, 색 위 회색 텍스트, 폰트 남발, bounce 이징.
- 배경은 **베이지가 아닌 순백/쿨그레이**, 폰트는 **산세리프**, 강조색은 **채도 높은 그린**으로 클로드 룩과 결별한다.

## 4. 색상 토큰 (Color Tokens)

### 브랜드 · 프레시 그린 (강조·액션 전용)
| 토큰 | HEX | 용도 |
|------|-----|------|
| green-50 | `#EAF7F0` | 보조 버튼 배경, 그린 틴트 영역 |
| green-200 | `#A7E8C6` | 약한 강조, 비활성 그린 |
| **green-500 ★** | `#16B364` | **주 강조색** (선택 칩, 배지, 주 버튼, 차트 라인) |
| green-600 | `#0E9F58` | 최저가 텍스트, hover/press |
| green-700 | `#0A7D45` | 가장 진한 강조 |

### 중립 (Neutral)
| 토큰 | HEX | 용도 |
|------|-----|------|
| text | `#1F1F1F` | 본문·제목 기본 텍스트 |
| sub | `#6B7280` | 보조 텍스트 |
| muted | `#9A9A9E` | 메타 정보(거리, 캡션) |
| line | `#F2F4F6` | 구분선 |
| surface | `#F6F7F9` | 카드 뒤 배경 영역 |
| white | `#FFFFFF` | 카드·헤더 표면 |

### 시맨틱 · 가격 변동 (가격 신호 전용)
| 토큰 | HEX | 용도 |
|------|-----|------|
| up (상승) | `#F03E3E` | 가격 상승 ▲ (한국 관례: 빨강) |
| down (하락) | `#3182F6` | 가격 하락 ▼ (한국 관례: 파랑) |

**색 역할 규칙 (중요):** 그린은 **브랜드·액션·강조**에만, 빨강/파랑은 **가격 변동 신호**에만 사용한다. 두 역할을 절대 섞지 않는다.

## 5. 타이포그래피 (Pretendard)

산세리프 단일 패밀리: **Pretendard** (한글·숫자 가독성 우수).

| 역할 | 크기/굵기 | 비고 |
|------|-----------|------|
| Display | 32 / 800 | 큰 가격 숫자 (히어로) |
| Title | 19 / 800 | 화면 제목 |
| Body-strong | 15 / 700 | 주유소명 등 강조 본문 |
| Body | 14 / 400 | 일반 본문 |
| Caption | 12 / 400 | 거리·메타, muted 색 |

- 숫자/제목에는 음수 자간(letter-spacing -0.02~-0.03em)으로 또렷하게.
- 세리프·장식 폰트 사용 금지.

## 6. 간격 · 모서리 · 그림자

- **간격 스케일:** 4 / 8 / 12 / 14 / 16 / 20 / 24 (px). 카드 내부 패딩 14~16, 카드 간 간격 10~14.
- **모서리(radius):** 칩 999(pill), 배지 6, 버튼 14, 카드 18, 히어로 20.
- **그림자:** 카드 `0 2px 10px rgba(0,0,0,0.05)` (은은하게). 과한 그림자·테두리 동시 사용 금지 — 그림자 또는 얇은 라인 중 하나.

## 7. 컴포넌트 언어 (Components)

- **필터 칩:** pill. 선택 시 green-500 채움 + 흰 텍스트, 비선택 시 흰 배경 + muted 텍스트 + 얇은 라인.
- **배지(최저가):** green-500 채움 + 흰 텍스트, radius 6, 작은 크기.
- **버튼:** 주 버튼 green-500 채움/흰 텍스트(radius 14, 700). 보조 버튼 green-50 배경 + green-600 텍스트.
- **주유소 카드:** 흰 카드(radius 18, 은은한 그림자). 좌측 주유소명(700) + 메타(muted), 우측 가격(800). 최저가는 green-600. 전일대비는 상승 빨강 ▲ / 하락 파랑 ▼.
- **히어로 카드(전국 평균):** green-500→green-600 그라데이션 배경, 흰 텍스트. 큰 가격(Display) + 반투명 pill 변동 배지.
- **추이 차트(recharts):** 라인 green-500(2.5px), 하단 그린 그라데이션 area fill(0.25→0). 마지막 포인트에 점.

## 8. 화면별 적용 메모

- **실시간 유가:** 상단 전국 평균 히어로 카드 + 유종 전환 칩 + 추이 차트. 숫자와 변동이 주인공.
- **주변 주유소:** 카카오맵 + 둥근 카드 가상 스크롤 리스트. 최저가 배지로 빠른 스캔 지원.
- **유가 뉴스:** 둥근 카드 뉴스 리스트. 동일한 카드 언어·여백 유지.

## 9. 결정 요약 (브레인스토밍 합의)

1. 성격: 친근한 소비자 앱 (B 구조: 둥근 카드 + 부드러운 그림자)
2. 강조색: 프레시 그린 `#16B364` (B3안)
3. 배경: 순백/쿨그레이, 폰트: Pretendard 산세리프
4. 가격 변동: 상승 빨강 / 하락 파랑 (그린과 역할 분리)
5. 라이트 모드 단일, 다크모드 보류
6. 클로드 룩(크림+점토색+세리프) 명시적 회피
